# Journey Operations Guide

## Before Journey

Required preparation:

- Journey objective
- Location
- Host coordination
- Schedule
- Participant registration
- Team assignment
- Communication plan

---

## During Journey

Operations:

- Check-in participants
- Coordinate teams
- Publish live updates
- Capture photos/videos
- Record observations
- Collect participant moments

---

## After Journey

Completion process:

- Media organization
- Participant follow-up
- Feedback collection
- Memory creation
- Field Journal development
- Evidence documentation

---

# Journey Roles

## Journey Leader

Responsible for overall execution.

## Contributor Team

Supports activities and documentation.

## Host Team

Supports local experience and community connection.

## Media Team

Captures stories and evidence.
