# TNC Operating Model

This document describes how TRẠM NỤ CƯỜI operates in the real world and how software should support that operation.

TNC is not only a content platform.

It is a living ecosystem connecting:

- People
- Journeys
- Local communities
- Experiences
- Stories
- Evidence
