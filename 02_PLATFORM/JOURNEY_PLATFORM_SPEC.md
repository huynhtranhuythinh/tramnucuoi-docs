# TNC Journey Platform Specification

## Journey Definition

A Journey is not only an event, tour or campaign.

A Journey combines:
- Location
- Story
- Participants
- Experience
- Live updates
- Media
- Memory
- Evidence

## Lifecycle

1. Draft
2. Open Registration
3. Preparation
4. Live Journey
5. Completed
6. Archive

## Live Journey

A real-time storytelling layer:
- Updates
- Photos
- Videos
- Comments
- Reactions

The purpose is not general social networking.

It is purpose-driven interaction around real experiences.
