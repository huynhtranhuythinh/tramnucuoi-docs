# CMS STRUCTURE --- TRẠM NỤ CƯỜI

## Principle

Public content must be editable without developers.

## Required Fields

### Pages

-   title_vi
-   title_en
-   content_vi
-   content_en
-   image
-   visibility
-   ordering

### Projects

-   name_vi
-   name_en
-   summary_vi
-   summary_en
-   detail_vi
-   detail_en
-   cover_image

### Journal

-   title_vi
-   title_en
-   excerpt_vi
-   excerpt_en
-   body_vi
-   body_en
-   category
-   tags
-   cover_image
-   status

### Media

-   image
-   title
-   description
-   usage

## Rules

Avoid hard-coded content. All important content should come from CMS.
