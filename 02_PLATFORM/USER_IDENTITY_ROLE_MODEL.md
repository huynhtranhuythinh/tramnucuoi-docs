# TNC User Identity & Role Model

## Principle

Every person starts as Explorer.

Roles are added through trust and contribution.

## Roles

### Explorer
Default role.
Can:
- discover journeys
- register
- follow live journeys
- save memories

### Contributor
Volunteer, collaborator, photographer, specialist.
Can:
- contribute media
- submit stories
- join missions

### Host
Local community representative.
Can:
- support assigned journeys
- provide local knowledge
- manage local experience information

### Partner
Organizations and CSR partners.

### Admin
System management role.

## Architecture

User Identity
+
Roles
+
Permissions

Role does not equal permission.
