# TRẠM NỤ CƯỜI Community & Journey OS Blueprint

## Vision

TRẠM NỤ CƯỜI Community & Journey OS is the operating layer connecting:
- People
- Journeys
- Local communities
- Experiences
- Memories
- Contributions
- Impact documentation

This is not a simple event management system.

It transforms the digital platform from a storytelling website into a living community operating system.

## Core Principles

### People First
Every person starts as Explorer and can grow into additional trusted roles.

### Journey First
Journey is the core operating unit containing:
- Place
- People
- Experience
- Contribution
- Story
- Memory
- Evidence

### One Identity — Multiple Roles
One user identity supports multiple roles:
- Explorer
- Contributor
- Host
- Partner
- Admin
