# Journey MVP Security And Permission

## Purpose

Define access principles.

------------------------------------------------------------------------

# Identity

One user identity supports multiple roles.

------------------------------------------------------------------------

# Explorer

Can:

-   view public journeys
-   register
-   access own memories

------------------------------------------------------------------------

# Contributor

Can:

-   submit content
-   upload approved media

------------------------------------------------------------------------

# Host

Can:

-   manage assigned journey information

------------------------------------------------------------------------

# Admin

Can:

-   manage users
-   manage journeys
-   approve content

------------------------------------------------------------------------

# Security Principle

Role does not equal permission.

Access requires:

Role + Permission + Ownership
