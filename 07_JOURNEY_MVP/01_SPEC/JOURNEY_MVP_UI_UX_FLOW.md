# Journey MVP UI UX Flow

## Purpose

Define the user experience flow for the first TRẠM NỤ CƯỜI Journey MVP.

The goal is to create a simple but meaningful journey experience.

------------------------------------------------------------------------

# Explorer Experience

## Discover Journey

User sees:

-   journey story
-   destination
-   schedule
-   duration
-   participation type
-   registration status

------------------------------------------------------------------------

## Journey Detail

Sections:

1.  Story
2.  Schedule
3.  Location
4.  Participants
5.  Registration
6.  Live Journey
7.  Memory Archive

------------------------------------------------------------------------

## Registration Flow

Discover

↓

View detail

↓

Register

↓

Confirmation

↓

Join Journey

------------------------------------------------------------------------

# Live Journey Experience

During active journey:

User sees:

-   timeline updates
-   photos
-   videos
-   reflections
-   comments

The experience should feel like following a living story.

------------------------------------------------------------------------

# After Journey

User receives:

-   personal memory
-   photos
-   videos
-   journey history

------------------------------------------------------------------------

# Admin Experience

Admin manages:

-   journey creation
-   participants
-   updates
-   media
-   completion archive
