# Journey MVP Content Model

## Purpose

Define content structure for Journey pages.

------------------------------------------------------------------------

# Journey Story

Contains:

-   Why this journey matters
-   Local context
-   Experience description

------------------------------------------------------------------------

# Schedule

Contains:

-   Day plan
-   Activities
-   Important moments

------------------------------------------------------------------------

# Live Updates

Content types:

-   Announcement
-   Photo Story
-   Video Moment
-   Reflection

------------------------------------------------------------------------

# Memory Content

Contains:

-   participant photos
-   videos
-   stories
-   highlights

------------------------------------------------------------------------

# Evidence Connection

Journey content can connect to:

-   Media Evidence
-   Field Journal
-   Project Documentation
