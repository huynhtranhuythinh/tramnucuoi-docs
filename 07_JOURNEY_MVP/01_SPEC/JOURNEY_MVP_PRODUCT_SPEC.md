# JOURNEY_MVP_PRODUCT_SPEC

## Purpose

This document defines the product scope of the first TRẠM NỤ CƯỜI
Journey MVP.

The goal is to create a complete but focused experience loop:

Before Journey → During Journey → After Journey

The MVP should prove that a TNC Journey can create:

-   participation;
-   experience;
-   connection;
-   memory.

------------------------------------------------------------------------

# Product Vision

A TNC Journey is not only a trip or event.

It is an experience connecting:

-   People
-   Places
-   Stories
-   Contributions
-   Memories

------------------------------------------------------------------------

# MVP Goal

Enable TNC to operate one complete real Journey.

A participant should be able to:

1.  Discover a Journey.
2.  Register.
3.  Participate.
4.  Follow live updates.
5.  Receive memories after completion.

------------------------------------------------------------------------

# User Roles

## Explorer

Default role.

Can:

-   discover journeys;
-   register;
-   participate;
-   view memories.

------------------------------------------------------------------------

## Contributor

Trusted contributor.

Can:

-   support operations;
-   contribute media;
-   submit stories.

------------------------------------------------------------------------

## Host

Local community role.

Can:

-   support assigned journeys;
-   provide local experience information.

------------------------------------------------------------------------

## Admin

Can:

-   create journeys;
-   manage participants;
-   publish updates;
-   manage content.

------------------------------------------------------------------------

# MVP Modules

## Journey Page

Contains:

-   story;
-   location;
-   schedule;
-   participation information;
-   registration.

------------------------------------------------------------------------

## Registration

Supports:

-   individual participants;
-   family participants;
-   contributors.

------------------------------------------------------------------------

## Participant Management

Admin can:

-   review applications;
-   approve participants;
-   track status.

------------------------------------------------------------------------

## Live Journey

Supports:

-   timeline updates;
-   photos;
-   videos;
-   reflections;
-   comments.

------------------------------------------------------------------------

## Memory Archive

After completion:

Participants receive:

-   photos;
-   videos;
-   journey history;
-   stories.

------------------------------------------------------------------------

# Out of Scope

Do not build:

-   full social network;
-   chat;
-   follower system;
-   gamification;
-   mobile app;
-   recommendation engine.

------------------------------------------------------------------------

# Success Criteria

MVP succeeds when:

A family can join a Journey and later return to view their memories.

TNC can:

-   organize;
-   operate;
-   document;
-   preserve the Journey.
