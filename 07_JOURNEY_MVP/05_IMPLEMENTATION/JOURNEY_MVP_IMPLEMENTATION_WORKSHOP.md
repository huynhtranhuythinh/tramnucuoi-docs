# Journey MVP Implementation Workshop

## Purpose

Translate Journey MVP documentation into a practical implementation
preparation phase.

Before coding, confirm:

-   existing system reuse;
-   implementation scope;
-   development sequence.

Documentation

↓

Implementation Decision

↓

Build Sprint

-   Journey entity
-   Registration

Do not build the entire ecosystem at once.
