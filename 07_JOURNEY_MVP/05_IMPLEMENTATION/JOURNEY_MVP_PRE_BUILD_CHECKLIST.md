# JOURNEY_MVP_PRE_BUILD_CHECKLIST

## Purpose

Final checklist before starting Lovable implementation for TRẠM NỤ CƯỜI
Journey MVP Milestone 1.

This checklist ensures:

-   documentation readiness;
-   architecture alignment;
-   build safety;
-   migration discipline.

------------------------------------------------------------------------

# 1. Documentation Check

Confirm:

-   [ ] Journey MVP Master Spec exists
-   [ ] Product specification exists
-   [ ] UX flow exists
-   [ ] Technical plan exists
-   [ ] Database architecture exists
-   [ ] Lovable build prompt exists
-   [ ] Milestone 1 task exists

------------------------------------------------------------------------

# 2. Architecture Check

Confirm:

-   [ ] Journey extends current platform
-   [ ] No separate application
-   [ ] No separate authentication
-   [ ] No duplicate media system
-   [ ] Existing CMS patterns are reused

------------------------------------------------------------------------

# 3. Backend Safety Check

Before migration:

-   [ ] Review Supabase schema impact
-   [ ] Review RLS policy impact
-   [ ] Review permission model
-   [ ] Confirm rollback approach

Never:

-   apply migration without review;
-   weaken security for speed.

------------------------------------------------------------------------

# 4. Build Scope Check

Milestone 1 includes:

-   [ ] Journey entity
-   [ ] Journey CMS
-   [ ] Journey listing
-   [ ] Journey detail
-   [ ] Registration
-   [ ] Participant management

Not included:

-   [ ] Live Feed
-   [ ] Comments
-   [ ] Reactions
-   [ ] Memory Archive
-   [ ] Social network features

------------------------------------------------------------------------

# 5. Lovable Execution Check

Before sending task:

-   [ ] Read /tnc-docs
-   [ ] Read Journey MVP documents
-   [ ] Understand existing architecture
-   [ ] Confirm no unrelated changes
-   [ ] Confirm no publish/deploy

------------------------------------------------------------------------

# 6. QA Check

After implementation:

-   [ ] TypeScript passes
-   [ ] Build passes
-   [ ] Responsive verified
-   [ ] Vietnamese verified
-   [ ] English verified
-   [ ] Auth unchanged
-   [ ] Existing pages regression checked

------------------------------------------------------------------------

# Final Approval Gate

Journey MVP Milestone 1 can proceed only when:

Documentation

-   

Architecture

-   

Security

-   

Scope

are confirmed.
