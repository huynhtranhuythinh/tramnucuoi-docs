# Journey MVP Scope Boundary

## Purpose

Prevent MVP expansion beyond the core objective.

------------------------------------------------------------------------

# Build Now

## Journey Foundation

-   journey creation;
-   registration;
-   participants.

## Live Experience

-   updates;
-   media;
-   basic interaction.

## Memory

-   completed journey archive.

------------------------------------------------------------------------

# Do Not Build Yet

Avoid:

-   full social network;
-   follower system;
-   private messaging;
-   advanced recommendation;
-   mobile app;
-   gamification;
-   marketplace.

------------------------------------------------------------------------

# Decision Rule

A feature should be included only if it strengthens:

Journey

-   

Experience

-   

Memory

-   

Relationship
